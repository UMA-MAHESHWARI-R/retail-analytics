# Retail Analytics Project

## 1. Project Overview

The Retail Analytics Project analyzes retail sales data to understand product performance, city-wise sales, monthly sales trends, and order status.

The project uses SQL Server, Python, Pandas, and Power BI to transform data into meaningful business insights and interactive visualizations.

## 2. Project Objectives

- Analyze total sales by product.
- Identify the highest-performing cities.
- Understand order status distribution.
- Calculate the total quantity sold for each product.
- Track monthly sales performance.
- Build an interactive Power BI dashboard.

## 3. Tools and Technologies

- **SQL Server:** Data querying and analysis.
- **Python:** Data processing and analysis.
- **Pandas:** Data manipulation.
- **Power BI:** Dashboard development and visualization.
- **Excel:** Data storage and preparation.

## 4. SQL Analysis

The following SQL queries are included in this project:

1. Sales by Product
2. Sales by City
3. Order Status Analysis
4. Total Quantity Sold by Product
5. Monthly Sales Analysis

## 5. Python Analysis

Python and Pandas are used to connect to the SQL Server database, retrieve data, and support data analysis.

## 6. Key Findings

Based on the retail sales analysis, the following insights were identified:

- **Total Sales:** ₹440,600
- **Total Orders:** 15
- **Average Order Value:** ₹29,373.33
- **Top-Performing Category:** Electronics, with sales of ₹356,000
- **Best-Selling Product by Sales Value:** Laptop, with sales of ₹165,000
- **Monthly Sales:** February recorded ₹150,500 in sales, the highest among January–April.

These findings help identify high-performing products, understand sales trends, and support data-driven business decisions.

## 7. Power BI Dashboard
